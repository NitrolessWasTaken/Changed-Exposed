An addon mod for the [Changed Minecraft Mod](https://github.com/LtxProgrammer/Changed-Minecraft-Mod) centered around Pale and its effects with flexible configuration.

### Planned features
| Feature            | State |
| ------------------ | :----: |
| Pale system rework |  🟨  |
| Pale prevention equipment |  🟥  |
| Pale centric Changed structures & facility rooms |  🟥  |
| Equipment to create a cure |  🟥  |
| Latex forms rebalance |  🟥  |
| Support for various addons |  🟥  |

and probably more...
